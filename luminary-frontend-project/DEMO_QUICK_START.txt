OPTION 2: With React (5-10 Minutes)
================================================================================

Prerequisites: You have Node.js installed

Step 1: Copy luminary-demo-frontend.jsx into your project's src/components/

Step 2: Update your App.jsx to import and use it:

    import LuminaryPMSDemo from './components/luminary-demo-frontend';

    function App() {
      return <LuminaryPMSDemo />;
    }

    export default App;

Step 3: Install dependencies if needed:

    npm install lucide-react

Step 4: Run your app:

    npm start

Step 5: Browser opens, demo runs ✓

Best for: Longer development, integrating with other code

================================================================================
OPTION 3: Use Vite (Ultra Fast - 5 Minutes)
================================================================================

Step 1: Create new Vite app:

    npm create vite@latest luminary-demo -- --template react
    cd luminary-demo
    npm install lucide-react

Step 2: Copy component to src/components/luminary-demo-frontend.jsx

Step 3: Update src/App.jsx (see Step 2 above)

Step 4: Run:

    npm run dev

Step 5: Open http://127.0.0.1:5174 ✓

Best for: Fresh start, fastest modern setup
